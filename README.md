# 脉冲图像重建模型 - 架构文档

## 📊 模型架构

### 整体结构
```
输入脉冲 → Encoder → Attention → Decoder → 重建图像
     ↓                              ↓
  下采样                          上采样 + 跳跃连接
```

### Encoder结构
| 层级 | 操作 | 输出通道 |
|------|------|----------|
| Conv1 | Conv → BN → ReLU → Spike → Pool | 64 |
| Conv2 | Conv → BN → ReLU → Spike → Pool | 128 |
| Conv3 | Conv → Residual → Spike → Pool | 256 |
| Conv4 | Conv → Residual → Spike | 512 |

### Decoder结构（混合注意力）
```
上采样 → Concat(跳跃连接) → 1x1卷积 → ChannelAttention → Residual → Conv
```

#### 混合结构 vs 纯交叉注意力

| 对比项 | 纯交叉注意力 | 混合结构 |
|--------|-------------|---------|
| 空间信息 | 严重压缩（8×8池化） | 完整保留（Concat） |
| 上下文细节 | 丢失高频信息 | 保留边缘纹理 |
| 重建质量 | 模糊 | 清晰 |
| 参数量 | 大（O(N²)） | 小（通道级） |
| 训练难度 | 高（复杂优化空间） | 低（梯度稳定） |

#### 通道注意力工作原理
```
输入特征 (B, C, H, W)
       ↓
  全局平均池化 → (B, C, 1, 1)  ← 统计全局信息
  全局最大池化 → (B, C, 1, 1)  ← 捕获显著特征
       ↓
  全连接层(C → C/r → C)
       ↓
  Sigmoid激活 → 通道权重 (B, C, 1, 1)
       ↓
  特征 × 权重 → 增强重要通道，抑制冗余通道
```

#### 关键优势
1. **细节保留**：跳跃连接直接传递编码器的高分辨率特征
2. **特征校准**：通道注意力动态调整通道重要性
3. **计算高效**：仅在通道维度计算，避免空间注意力的O(N²)复杂度
4. **梯度稳定**：残差结构保证训练稳定性

### 注意力机制

#### 1. 通道注意力 (ChannelAttention)
```
输入 → 全局平均池化 + 最大池化 → 全连接层(C→C/r→C) → Sigmoid → 特征×权重
```

#### 2. 自注意力 (AttentionMechanism)
```
输入 → LayerNorm → QKV投影 → Multi-Head Attention → 残差连接 → 输出
```

#### 3. Linear注意力 (LinearAttentionMechanism)
```
输入 → LayerNorm → QKV投影 → ELU(Q) × (ELU(K)^T × V) → 残差连接 → 输出
```

### 核心组件

#### 脉冲神经元 (SpikingNeuron)
- 阈值: 1.0
- 衰减系数: 0.9
- 替代梯度: Sigmoid(5 × (膜电位 - 阈值))

#### 残差块 (ResidualBlock)
```
输入 → Conv1 → BN → ReLU → Conv2 → BN → 残差连接 → ReLU → 输出
```

### 损失函数
```
Loss = 0.6 × MSE + 0.25 × Perceptual + 0.15 × HOTV

其中:
- MSE: 均方误差
- Perceptual: (均值误差)² + (标准差误差)²
- HOTV: 二阶广义总变分
```

### 自适应机制
```
1. 计算注意力矩阵最大奇异值占比
2. 如果占比 > 0.7，自动切换为Linear注意力
3. 重新训练模型
```

### 数据流示例 (128×128输入)

| 层级 | 形状变化 | 通道数 |
|------|---------|--------|
| 输入 | 1×128×128 | 1 |
| Conv1+Pool | 64×64×64 | 64 |
| Conv2+Pool | 128×32×32 | 128 |
| Conv3+Pool | 256×16×16 | 256 |
| Conv4 | 512×8×8 | 512 |
| Attention | 512×64 | (展平) |
| Decoder | 256×16×16 → 128×32×32 → 64×64×64 → 1×128×128 | 逐步减少 |
